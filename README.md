Angel One Power BI Dashboard

An interactive Power BI dashboard designed to analyze customer activity, portfolio performance, trading activity, and revenue.

Project Overview

This project provides business insights through an interactive Power BI dashboard. It helps analyze key areas such as customer behavior, portfolio activity, trading performance, and revenue trends.

Tools & Technologies

- Power BI
- Microsoft Excel
- DAX
- Data Visualization

Dashboard Features

- Customer analysis
- Portfolio analysis
- Trading activity analysis
- Revenue analysis
- Interactive filters and visuals
- Trend and performance analysis

Project Files

- "Angel One Business Insights Dashboard PDF.pdf" — Dashboard report
- "angel one dashboard project.pbix" — Power BI project file

Purpose

The objective of this project is to demonstrate practical skills in data analysis, dashboard development, business intelligence, and financial data visualization using Power BI.
